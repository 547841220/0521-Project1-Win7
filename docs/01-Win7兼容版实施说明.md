# Win7 兼容版实施说明

## 定位

该版本用于 Windows 7 老电脑试用，和当前 Tauri 正式版并行存在。它不是正式版的兼容补丁，而是一条独立交付线。

## 一致性约束

功能内容保持一致：

- 业务模块一致
- 字段含义一致
- 计算口径一致
- 导出文件结构一致

页面尽量保持一致：

- 左侧导航
- 首页指标卡
- 每个模块上方录入、下方明细
- 利润核对和总账核对在同一页面

不承诺像素级一致：

- Swing 控件和 Tauri/React 控件渲染不同
- Windows 7 字体和现代 Windows 字体不同

## 当前版本边界

- 不做云同步
- 不做权限
- 不做 AI
- 不做数据库迁移
- 不做自动升级
- 不做公账/固定账分摊到地块

## 后续可增强

1. 增加一键备份/恢复。
2. 增加内置 JRE 的免安装包。
3. 增加 Excel `.xls` 原生导出。
4. 增加和正式版的数据互导。
5. 增加 Win7 真机截图验收文档。

## 安装包方案

当前已准备 Inno Setup 打包配置：

- `package-windows-installer.bat`
- `installer/FieldLedgerWin7.iss`
- `package/run-app.bat`
- `.github/workflows/windows7-build.yml`

最终客户拿到的是一个 `.exe` 安装包。安装包内包含：

- 应用 jar
- Java 8 JRE
- 启动脚本
- 桌面快捷方式

客户侧不需要安装 Java，也不需要配置环境变量。

安装目录使用：

```text
%LOCALAPPDATA%\AiMoneyFieldLedgerWin7
```

这样可以减少 Windows 7 上没有管理员权限导致安装失败的概率。

## GitHub Actions 交付流程

优先使用 GitHub Actions 打包，避免本地准备 Windows 打包机：

1. Actions 安装 Java 8。
2. 编译 Swing 程序为 `field-ledger-win7.jar`。
3. 把 Java 8 运行环境复制到 `package/jre`。
4. 安装 Inno Setup。
5. 生成单文件安装包。
6. 上传 artifact：`windows7-compatible-installer`。

下载 artifact 后，只需要把里面的 `.exe` 发给客户。
